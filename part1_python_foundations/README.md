# TrendPulse — Part 1: Python Foundations



## Project Overview

This part analyzes trending YouTube videos from the United States, Great Britain, and India using Python fundamentals. The analysis will use the provided CSV datasets to explore video trends and engagement.



## Dataset

Dataset: Trending YouTube Video Statistics

Source: Public dataset originally published on Kaggle.



Files used:

- `USvideos.csv`

- `GBvideos.csv`

- `INvideos.csv`

- `categories.csv`



All required data files are stored in the `data/` folder.



## Requirements

- Python 3

- Google Colab

- pandas

- NumPy



Install dependencies locally with:



```bash

pip install -r requirements.txt

```



## How to Run

1. Open `trendpulse_part1.ipynb` in Google Colab.

2. Ensure the required CSV files are available in the `data/` folder.

3. Run all notebook cells from top to bottom.



## Design Decisions

- Use three country datasets to compare trending videos across countries.

- Inspect the actual column names and data quality before analysis.

- Keep the notebook organized into sections with short Markdown explanations.

- Use transparent Python logic and explain findings using evidence from the data.



## Limitations

The dataset represents historical snapshots of YouTube trending lists. It does not represent every video uploaded to YouTube or current real-time popularity.
